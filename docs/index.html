Pashu-Aahar

An offline cattle nutrition calculator for small dairy farmers. Enter cow details, set a milk yield target, and get a balanced home feed recipe using local grains.

Built for the project requirements

The native Android project includes the requested farmer profile flow, recipe generator, cost tracker, chart, offline logic, fodder icons, and veterinary tips.

1

Cow Profile

Breed, age, and weight inputs help estimate roughage and concentrate needs.

2

Recipe Generator

Milk yield targets produce maize, cottonseed cake, wheat bran, and mineral mix quantities.

3

Cost Tracker

Daily and monthly savings are compared against market cattle feed prices.

4

Veterinary Tips

Bundled offline guidance covers hygiene, fodder storage, gradual diet changes, and minerals.

5

Offline First

No server is required after installation because the formula engine is packaged in the app.

6

Charts

The Android app uses MPAndroidChart to visualize home feed cost, market cost, and savings.

Native Android implementation with a small static project page for live submission preview.
